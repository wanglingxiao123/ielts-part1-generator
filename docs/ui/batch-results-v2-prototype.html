🎨 V2 改进说明

  • 去掉内部评分标签 — 不展示 PASS/MINOR_EDITS 等 Agent 内部评价结果，统一只显示"待审核"
  • 保留「对比本场景」按钮 — 放在场景 Header 右侧，点击后进入对比模式：用户点选该场景下的任意两套材料进行并排对比（支持 2 套以上时选 2 对比）
  • 对比模式 — 进入后顶部出现紫色提示条 + A/B 颜色图例，被选中的两张卡片分别标记蓝色（A）和紫色（B）边框
  • 支持 3+ 套材料 — 网格布局自适应列数（2列 or 3列），未来场景生成 3 套直接兼容
  • 勾选 + 提交审核 — 底部固定操作栏，实时显示已选数量，一键提交所有选中材料进入审核队列
  • 预览摘要 — 每张卡片展示对话第一句 + 一行简述（话题+干扰类型），不用点进去就能快速区分不同材料
  • 信息点圆点 — 保留，黄色表示该信息点分布有问题（Agent 评价中标记的），用户可快速扫描
  • 去掉评分分数条 — 内部质量评估结果不暴露给用户，只通过信息点圆点的颜色间接体现
