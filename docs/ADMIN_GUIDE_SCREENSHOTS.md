## 截图方式

- 使用浏览器截图，PNG 原图，建议桌面宽度 1440 像素左右、缩放 100%；优先保证正文和按钮可读。
- 普通页面保留标题、关键状态与操作区；弹窗保留完整弹窗和少量背景，不需要浏览器地址栏或开发者工具。
- 统一使用同一个演示场景和模型，保留版本编号及差异状态，方便读者关联步骤。
- 账号邮箱可替换为演示邮箱或打码；密码、临时密码及其他凭证内容必须完全遮挡，不能只模糊。
- A08/A10/A11/A13/A14 打开弹窗后截图即可，拍完取消，不必为了截图发布、回滚或改变他人账号。
- A15 仅在已有测试账号的密码重置演示中拍摄，不要为截图重置真实用户密码。暂时没有合适账号可后补。
- 不必为了截图发布测试提示词；完整场景对比已有合适历史结果时可直接使用。
