## Capture Guidelines

- Use PNG format and keep the file names exactly as listed above.
- Capture at a consistent browser width, preferably 1440 px.
- Keep the relevant controls and their surrounding context visible.
- Do not include browser tabs, bookmarks, desktop notifications, or unrelated windows.
- Use demonstration accounts and materials only; remove personal or sensitive information.
- Do not add arrows or text to the image. Documentation annotations can be added later.
