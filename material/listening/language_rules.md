# Language Rules (`LG-xxx`)

## 适用范围

检查考生可见文字和可听脚本的英语质量。语言规则不用于惩罚合法口语特征；只有影响清晰度、公平性或专业质量时才生成缺陷。

| Rule ID | 要求 | 默认严重度 | 核验要点 |
| --- | --- | --- | --- |
| `LG-001` | 语法必须正确；对话中的省略、停顿和自我修正若自然且清楚则允许。 | `MINOR`；改变答案时 `MAJOR` | 区分口语特征与错误。 |
| `LG-002` | 用词和搭配必须自然、符合语境与说话者角色。 | `MINOR` | 避免翻译腔和异常搭配。 |
| `LG-003` | 正式度、礼貌程度和术语密度必须符合社会/教育场景。 | `MINOR` | speaker relationship 与 register。 |
| `LG-004` | 同一制品的拼写变体应一致；默认可采用英式英语，但不得把正确变体误判为错误。 | `MINOR` | programme/program 等。 |
| `LG-005` | 标点和大小写必须支持清晰阅读，不得造成题意或答案边界歧义。 | `MINOR`；影响作答时 `MAJOR` | 特别检查选项和 completion。 |
| `LG-006` | 指令必须简洁、直接、术语一致；相同操作不得使用相互冲突的动词。 | `MAJOR` | choose/write/match/label。 |
| `LG-007` | 代词、指示词和省略成分必须有明确先行词。 | `MINOR`；影响答案时 `MAJOR` | this/that/it/they。 |
| `LG-008` | 名称和术语在脚本、题面、key 与 asset 中的拼写必须一致。 | `MAJOR` | 与 `AL-009` 去重报告。 |
| `LG-009` | 数字、日期、时间、货币和单位的表达必须自然且不产生地区性歧义。 | `MAJOR` | 如 03/04、billion、12-hour time。 |
| `LG-010` | 内容必须使用包容、中性的表达，除非相关差异是教育性主题且被客观处理。 | `MINOR`；歧视伤害为 `MAJOR` | 性别、族群、残障、年龄等。 |
| `LG-011` | 不得使用不必要的冒犯、羞辱或刻板印象来制造语境或干扰项。 | `MAJOR` | 结合 `SR-011`。 |
| `LG-012` | 人名、地名和术语应可发音且必要时在脚本中自然澄清；不得靠罕见拼写陷阱测无关能力。 | `MINOR`；影响公平性时 `MAJOR` | 拼读是否自然提供。 |
| `LG-013` | 题干和选项应避免否定范围歧义、双重否定和不必要的复杂嵌套。 | `MAJOR` | 逻辑极性。 |
| `LG-014` | 同一对象应使用稳定称谓；缩写首次出现时应能从音频或题面理解。 | `MINOR`；影响答案时 `MAJOR` | acronym resolution。 |
| `LG-015` | 修订后的题干、carrier 和选项不得仅为“更高级”或“与 Script 不同”而增加词汇难度。应删除同一题干及相邻题面中无必要的实义词重复，并优先使用自然、常用、符合目标学生水平且便于从局部音频定位的表达；把常见 Script 措辞替换为更生僻、抽象、隐喻化或迂回的说法不合规。专名、固定术语和不泄露答案的 Script 原词/signpost 可以保留，不得为避免重复而机械换同义词。 | `MINOR`；妨碍定位、形成答案镜像或影响公平作答时 `MAJOR` | 比较 Script 与题面词汇难度、重复实义词、搭配自然度和语义距离；记录必要原词及不泄露答案的理由。 |

## 去重规则

语言错误若已经造成答案错误、对齐失败或指令不可执行，应以对应 `AR`、`AL` 或 `QR` 规则作为主 finding，并把 `LG` 规则放入 `related_rule_ids`。
