# Structural Rules (`SC-xxx`)

## 适用范围

用于检查整套 Listening 内容、Part 划分、题号、题型和输入完整性。`SC-001` 至 `SC-007` 依据 IELTS 官方公开格式；其余为本项目数据完整性基线。

| Rule ID    | 要求                                                                                                                                                                                                                                                                                                                                                                                                     | 默认严重度                                                                            | 核验方法                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `SC-001` | 完整测试必须包含恰好 4 个 Part，编号为 1–4。                                                                                                                                                                                                                                                                                                                                                            | `MAJOR`                                                                             | 检查`content.parts[].part_number`。专项片段输入不适用，但必须标记部分覆盖。                                          |
| `SC-002` | 完整测试每个 Part 必须有 10 题，总计 40 题。                                                                                                                                                                                                                                                                                                                                                             | `MAJOR`                                                                             | 按 Part 统计`questions`；片段输入不适用。                                                                            |
| `SC-003` | 完整测试题号必须唯一、连续并覆盖 1–40；`question_id` 在整个输入中唯一。                                                                                                                                                                                                                                                                                                                               | `MAJOR`                                                                             | 检查重复、缺号、跨 Part 错位。                                                                                         |
| `SC-004` | Part 1 为日常社会语境双人对话；Part 2 为日常社会语境独白；Part 3 为教育/培训语境中两名主要说话者的对话（可有其他发言者）；Part 4 为学术主题独白。                                                                                                                                                                                                                                                        | `MAJOR`                                                                             | 结合`context`, `speaker_count` 与脚本角色核验。                                                                    |
| `SC-005` | 每个 Part 的题目必须对应本 Part 的录音内容，不得依赖另一 Part 才能作答。                                                                                                                                                                                                                                                                                                                                 | `MAJOR`                                                                             | 逐题检查 evidence 的`part_number`。                                                                                  |
| `SC-006` | 题目所需信息应按录音推进顺序出现；同一组内允许题型固有的局部选择，但不得要求无提示地逆序追溯。                                                                                                                                                                                                                                                                                                           | `MAJOR`                                                                             | 比较题号与首个决定性证据的时间/turn 顺序。                                                                             |

| `SC-009` | Part、turn、question、asset 的 ID 与引用必须唯一且可解析。                                                                                                                                                                                                                                                                                                                                               | `MAJOR`                                                                             | 建立 ID 索引并验证所有引用。                                                                                           |
| `SC-010` | 依赖地图、平面图、图示或图片的题目必须提供对应 asset 及完整 label/region 数据。                                                                                                                                                                                                                                                                                                                          | `MAJOR`                                                                             | 检查`asset_refs` 与 `assets`。                                                                                     |
| `SC-011` | 若提供时间戳，必须为非负、同一 turn 中`start_ms < end_ms`，并在 Part 内单调不倒退。                                                                                                                                                                                                                                                                                                                    | `MINOR`；影响证据定位时 `MAJOR`                                                   | 验证数值与顺序。                                                                                                       |
| `SC-012` | 考生可见题面、题组标题/小标题、无 blank signpost、示例、相邻 carrier、文件名、asset label、注释或元数据不得直接泄露标准答案。Completion 必须同时执行 `QR-040` 的题组级 exact/inflectional 与语义泄漏检查。 | `MAJOR`；系统性为 `CRITICAL` | 隐藏 Script/answer key，按题组搜索 canonical answer、单复数/常规屈折变化与明显答案标记；再人工检查同一事实的近直述。 |
| `SC-013` | 同一题只能归属一个 Part；题号范围不得重叠。                                                                                                                                                                                                                                                                                                                                                              | `MAJOR`                                                                             | 检查 question ownership。                                                                                              |
| `SC-014` | 完整测试中每个 Part 必须包含脚本和至少一个题组；空 Part 不合规。                                                                                                                                                                                                                                                                                                                                         | `MAJOR`                                                                             | 检查`script_turns` 和 `questions` 非空。                                                                           |
| `SC-015` | Part 1（日常社会语境双人对话）的题型应以 form/note/table completion 为主，用于记录姓名、号码、地址、日期、时间、费用、预约、服务等事实细节。新生成或重做的 note completion 应保持自然的记录层级，避免十题集中测试同一微型信息类别，并按 `QR-031` 提供简短、非答案泄露的场景标题。 | `MINOR`；若题型与该 Part 的语境、证据结构不匹配导致作答依据不成立，升级为 `MAJOR` | 汇总 Part 1 的 `question_type`、答案信息类别、notes 层级和场景标题；结合 Script 判断题型是否适配当前语境。标题要求只适用于新生成或重做的 Part 1 notes。 |
| `SC-016` | Part 2（日常社会语境独白）用于说明场地、设施或安排。按题组出现顺序，题型组合只允许以下之一：single choice + matching；matching + single choice；multiple choice + matching；single choice + multiple choice；single choice + matching + single choice；matching + multiple choice；single choice + diagram labelling；multiple choice + matching + single choice；multiple choice + single choice。未列出的组合判为不合规。        | `MAJOR`                                                                             | 按题组出现顺序提取 Part 2 每个题组的类型，组合成序列后与允许列表逐项比对；顺序不同视为不同组合。                       |
| `SC-017` | Part 3（教育/培训语境多人讨论）用于呈现观点讨论与信息细化。按题组出现顺序，题型组合只允许以下之一：single choice + matching；matching + single choice；multiple choice + matching；single choice + multiple choice；single choice + matching + single choice；matching + multiple choice；single choice + diagram labelling；multiple choice + matching + single choice；multiple choice + single choice。未列出的组合判为不合规。 | `MAJOR`                                                                             | 按题组出现顺序提取 Part 3 每个题组的类型，组合成序列后与允许列表逐项比对；顺序不同视为不同组合。                       |
| `SC-018` | Part 4（学术独白）必须统一使用 note completion，并覆盖 Q31–Q40。若 Script 没有两个或以上 narrator 题号窗口，Part 4 必须是单一 `Questions 31–40` 题组；若 narrator 明确拆分窗口，则必须按每个窗口各设一个 note-completion 题组，题组范围与窗口完全一致。每个题组统一使用 `Complete the notes below.` 和 `Write ONE WORD ONLY for each answer.`，不得混入 sentence/summary/table completion、short answer、matching 或选择题。 | `MAJOR` | 按题组顺序核对 Part 4 全部题型、范围和指令；再与 `SC-019` 的 narrator 窗口逐一比对。无拆分时只允许 Q31–Q40 一个题组；有拆分时只允许与窗口一一对应的 note-completion 题组。 |
| `SC-019` | 若源 Script 中的 narrator 以 `look at questions X to Y` / `answer questions X to Y` 等可听指令将一个 Part 明确划分为两个或以上题号窗口，这些窗口是不可破坏的结构边界：题组范围不得跨窗口，每题的决定性证据和 annotated-script 标签必须位于宣布作答该题号范围之后、下一个题号窗口提示之前。不得为迁就改写题目而修改可听 narrator 正文。若 Script 未提供两个或以上明确题号窗口，可在满足其他结构、证据和顺序规则的前提下自由重组。 | `MAJOR` | 直接从 Script Word 提取 narrator 题号窗口；核对窗口是否完整分割该 Part，题组范围是否全部属于单一窗口，以及每个 Q 标签是否位于对应 answer cue 之后、下一窗口 cue 之前。 |
| `SC-020` | Word comments 必须完成可追踪处置。任何声称“comments resolved/reviewed”的 candidate 必须覆盖源 Question DOCX 的全部 comments，并且未解决数为 0；删除 comment 不是处置。保留或延期的 comment 必须记录理由、负责人和目标版本，且该 candidate 不得声称 comments 已全部解决。声学/音频类 comment 还必须按 `SR-022` 记录 `verification_kind=audio` 与时间点；没有实际音频身份和核验证据时只能延期。 | `MAJOR` | 以源 Question DOCX 与最终 candidate 的 OOXML comments 清单做双向比对；记录 comment ID、作者、正文、锚点、源状态、最终状态和 disposition。无源文件或 disposition map 时不得证明“全部解决”；音频类关闭项核对 audio SHA-256/版本、timestamp 和听音证据。 |

上述 `SC-015`–`SC-018` 中的题型仍须取自 `SC-007` 允许的枚举。`SC-016`/`SC-017` 中的 single choice 与 multiple choice 均对应 `question_type = multiple_choice`：single choice 指每题从选项中仅选 1 个（如三选一）；multiple choice 指题组要求从更长选项列表中选 2 个或以上（如 “Choose TWO/THREE letters”，对应多个题号共用一组选项与合并评分）。diagram labelling 对应 `SC-007` 中的 plan/map/diagram labelling；matching 对应 `question_type = matching`。判定选择数量以该题组 `instruction`/`answer_format` 明示的选择数量与评分键的答案数量为准，而非题号数量。`SC-018` 是 Part 4 的固定生成合同，不参与 Part 2/3 的题型随机选择。

## 报告要求

- 对完整套卷规则和片段输入做区分；片段不因缺少其余 Part 自动失败。
- 当 `SC-001`/`SC-002` 不适用于片段时，在 `coverage.unreviewed` 说明，而不是生成虚假 finding。
- 结构 finding 必须给出 JSON path、Part 或题号范围。
- `SC-015` 描述的是 Part 1 的典型题型分布而非强制唯一取值；偏离典型分布本身不直接判定违规，需结合语境与证据是否成立综合判断，避免仅因题型少见就误报。
- `SC-015` 的标题要求按 `QR-031` 仅适用于新生成或重做的 Part 1 notes；历史原件只审查而不因缺标题倒推失败。
- `SC-016`、`SC-017` 是 Part 2、Part 3 题型组合的强制枚举列表；题组类型序列不在允许列表内即判定为违规，不适用“典型但可偏离”的从宽判断。
- `SC-018` 是 Part 4 的强制固定形式；只有 `SC-019` 识别出的 narrator 多窗口可以改变题组数量和范围，不能改变 note-completion 题型、固定指令或一词答案限制。
- `SC-019` 只在 Script 实际存在两个或以上 narrator 题号窗口时强制窗口边界；无明确拆分时不得伪造窗口限制。
- `SC-020` 的自动检查只能证明 candidate 内仍有多少 unresolved comments；要证明 comment 没有被静默删除，必须同时提供源 Question DOCX 或与其哈希绑定的 disposition map。
