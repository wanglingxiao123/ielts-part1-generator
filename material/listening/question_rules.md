# Question Rules (`QR-xxx`)

## 适用范围

检查考生可见的题目、指令、选项、空格和题组结构。题目是否被脚本支持由 `AL-xxx` 和 `AR-xxx` 最终判定。

| Rule ID | 要求 | 默认严重度 | 核验要点 |
| --- | --- | --- | --- |
| `QR-001` | `question_type` 必须是 `SC-007` 支持的类型，且数据结构与该类型一致。 | `MAJOR` | 类型、stem、options、blank、asset 的组合。 |
| `QR-002` | 每个题组必须有清楚、完整、与题型兼容的作答指令。 | `MAJOR` | 选择字母/文字、选择数量、字数限制、是否可重复使用。 |
| `QR-003` | 题干必须只存在一种合理解释，不得缺少决定作答范围的主语、时间或限定词。 | `MAJOR` | 语义范围和修饰关系。 |
| `QR-004` | 题号顺序必须与决定性录音证据的顺序一致。 | `MAJOR` | 与 `SC-006`/`AL-003` 联合检查。 |
| `QR-005` | 地图、平面图、图示和图片题必须能通过提供的 asset 完整作答；方向、起点、图例和标签应清楚。 | `MAJOR` | asset 可见信息和录音指示。 |
| `QR-006` | 选择题选项必须互斥、同层级、语法平行，不得出现包含关系导致多个选项同时成立。 | `MAJOR` | 逐对比较 option scope。 |
| `QR-007` | 干扰项在题面上必须可信、同层级且不依赖荒谬内容或排版差异来突出正确项。历史原件的录音激活缺口按 `SR-008` 单独扫描；新生成或重做的 single choice / multiple-selection 还必须满足 `QR-036` 的实质激活门槛和 `QR-039` 的前置近距门槛。若干扰项不可信、与正确项不互斥、无需听音频即可排除，或属于新改 choice 但没有可追溯音频状态/位置，均必须改题。 | `MAJOR`（题面可信性或新改 choice 的激活/位置覆盖）；历史原件的纯音频激活缺口为 `ADVISORY_WARNING` | 先隐藏 Script 检查选项可信性和 no-audio fairness；再记录每个 option 的最小音频证据、状态、相对答案位置和句距，区分历史扫描与新改题验收。 |
| `QR-008` | 题目不得在不听录音的情况下，通过词形、单复数、数量或语法搭配、选项长度、大小写、题干与选项的独特词汇镜像、语义类别、重复措辞或相邻题答案暴露正确选项。若上述线索能稳定推出答案，即使录音本身支持该答案，仍属答案泄露。Matching 必须额外建立 answer-blind compatibility matrix：隐藏 Script/答案后，每个 item 至少应有两个题面上合理兼容的 options；若仅凭 item 类别或常识即可唯一配对，则失败。 | `MAJOR` | 隐藏 Script 和答案执行 no-audio solvability audit；逐项检查 morphology/cardinality/grammar、lexical overlap、option length、semantic category 与 cross-item leakage；matching 记录每个 item 的 `compatible_options_without_audio`。 |
| `QR-009` | completion 题在填入标准答案后必须语法正确、语义通顺。 | `MAJOR` | 冠词、单复数、搭配、句法。 |
| `QR-010` | blank 必须对应有意义的信息单位，不得允许过宽答案范围或要求猜测未说出的词。若 Script 在局部证据中列出多个同层级名词、属性、原因、材料、感受或步骤，carrier 必须给出足够限定，或明示其他并列成员，使除 canonical answer 外的候选代入均不成立。 | `MAJOR` | 检查 blank 边界与上下文；对 enumeration/list evidence 执行 `AR-012` 全候选代入审计。 |
| `QR-011` | 每题要求的答案数量必须明确，并与评分键的答案数量一致。 | `MAJOR` | “Choose TWO”、多空题、short answer。 |
| `QR-012` | Matching 指令必须明确说明字母是否可以重复使用，并与最终 answer key 保持一致。若写明 `Use each letter once only.`，同一 option ID 不得重复；若写明 `A letter may be used more than once.`，同一 option 可在不同 item 中复用，但每次复用都必须由各自独立、明确的 Script 关系支持。选项标识必须唯一且清楚。 | `MAJOR` | 解析 instruction 的 reuse contract；核对 audit 中的 `reuse_allowed` 与 answer key。不得把“必须禁用复用”当作 IELTS 的普遍规则。 |
| `QR-013` | multiple choice 必须明确选择一个还是多个；正确答案数量必须匹配。 | `MAJOR` | single/multiple selection。 |
| `QR-014` | 一题答错不得自动导致后续题无法独立作答，除非题型本身明确且公平。 | `MAJOR` | 连锁引用、前题答案复用。 |
| `QR-015` | 题面中的题号、指令、stem、options、blank、asset label 和其他作答必需信息必须可访问、可辨认；不得仅用颜色、精细图形或不可辨符号传达必要区别。纯字体、间距、边框、颜色偏好、非破坏性分页或视觉一致性问题不属于内容人工 review 的阻断项；只有这些问题隐藏、遗漏、错序或使必需内容无法可靠读取时才失败。 | `MAJOR`（必需内容不可访问/不可读）；纯样式偏差为 `MINOR`/`INFO` 并只影响 `visual_qc_status` | 先确认 reviewer 能读取并区分全部必需内容；再把不影响内容读取的视觉偏差单独记录，不得延迟首轮内容 review。 |
| `QR-016` | 题组指令的适用范围必须清楚，题号区间与实际题目完全一致。 | `MAJOR` | 例如 “Questions 11–15”。 |
| `QR-017` | completion/short-answer 题必须明确字数和数字限制；限制应可由答案满足。 | `MAJOR` | `answer_constraints` 与 instruction 一致。 |
| `QR-018` | 不得要求使用录音中不存在的知识、计算或推断层级来决定答案。 | `MAJOR` | 可接受简单语义推断，不接受外部知识。 |
| `QR-019` | 题干与选项不得包含与录音事实相冲突的预设。 | `MAJOR` | 检查名称、单位、时间范围和对象。 |
| `QR-020` | 示例题若存在，必须明确标记且不得计入 40 道计分题或造成编号冲突。 | `MAJOR` | `is_example` 与 numbering。 |
| `QR-021` | 单项选择题可以要求对局部内容进行改述、整理或简单推断，但决定性证据必须集中在连续的 1–2 句内；不得要求概括整段、整场对话或独白、或整个 Part 的主旨、主题、总体目的或整体结论，也不得合并相距较远的信息进行归纳。 | `MAJOR` | 先判断题干指向的是局部对象还是整体内容，再定位最小决定性证据；若答案需要超过连续 2 句、跨不相邻位置或综合全文/整段信息，则判为不合规。不得仅因题干包含 `main`、`focus` 等词机械判定，局部职责、原因或概念作用仍可合规。 |
| `QR-022` | 每道题的决定性证据必须尊重 `SC-019` 识别的 narrator 题号窗口：前一窗口题目的答案不得延后到后一窗口，后一窗口题目的决定性证据也不得提前。候选人可见的 Form/Note/Table 页面题组边界由自然任务与版式结构决定，可以连续覆盖两个 narrator 窗口；不得仅因中段读题旁白拆开一个连续结构，也不得为减少题组数合并不同结构。 | `MAJOR` | 将每题 evidence 与 Script Word 中的 narrator 窗口逐一比对；另独立检查页面题组是否构成自然、连续的任务结构，不以窗口数量推导题组数量。 |
| `QR-023` | Part 4 的每个 note-completion 题组必须在内容结构上构成完整 notes：有一个主题标题、至少两个与讲座结构一致的分层小标题、项目符号，以及按证据顺序嵌入正文的题号与空格。不得把 Q31–Q40 排成十个彼此割裂的句子，也不得用排版伪装成 notes。面板可优先使用可见边框；若 narrator 多窗口要求拆组，则每个窗口各使用一个同类面板。标题、层级、项目符号和题号/blank 顺序属于内容门槛；边框粗细、字体、间距、视觉一致性和非破坏性换页只影响 `visual_qc_status`，不阻断内容人工 review。 | 内容结构缺失或必需内容不可读为 `MAJOR`；不影响读取的视觉偏差为 `MINOR`/`INFO` | 先以 Word 结构确认标题、小标题、项目符号、题号顺序和 blank 足以供内容 review；最终成品再逐页检查边框、缩进、换页和视觉一致性。若渲染隐藏或截断必需内容，按 `QR-015` 阻断。 |
| `QR-024` | 受控改述必须服务于听力理解，不得为追求词面差异而牺牲自然度和可定位性。single choice 的题干和正确选项应使用忠实、常用且局部可定位的措辞；不设机械同义替换指标，Script 原词或连续短语可以直接保留，但不得因题干镜像、只有正确项使用原词、选项长度/格式异常或常识关系而在无音频时暴露答案。若正确项保留较长原句片段，其他 options 也必须有平衡的 Script provenance、自然表述和同层级可信性。completion 的 canonical answer 仍须遵守原词与字数限制；blank 周边 carrier 可作最小必要的词汇或句法重组，并可保留不泄露答案的关键 signpost。matching 的 item 和 option 同样不设强制同义替换指标，可以保留或直接使用 Script signpost；但仍必须通过 `QR-008`，不得靠 item-option 词汇镜像、语法或常识在无音频时推出配对。题干、item、carrier 和 options 应删除无必要的实义词重复；专名、固定术语及有助定位的 Script 原词可以保留，但必须记录 exact/signpost 理由，并确认该词不会复现 canonical answer、形成正确项独有的题面镜像或通过相邻题暴露答案。任何实际使用的改述都不得引入 Script 未出现的对象或语境，也不得改变主体、范围、极性、时间、因果、比较、情态或答案粒度；优先使用学生熟悉的自然表达，避免把常见 Script 措辞替换为更生僻、抽象或迂回的表达。 | `MAJOR`；仅不影响定位和作答的轻微重复或措辞优化可为 `MINOR`/`INFO` | completion 和 single choice 记录 `script_phrase -> question_phrase` map；choice/matching 另记录 `stem_lexical_reuse_result`、保留原词及理由、`answer_leakage_result`。matching 记录 `paraphrase_not_required` 并执行 no-audio audit。人工确认 exact/partial/paraphrase 均能从连续局部证据直接定位，且不存在机械重复、为词面变化增加的额外词汇推断或答案词镜像。 |
| `QR-025` | Part 4 notes 除十个计分 blank 外，必须包含足够的无 blank 完整内容作为讲座导航；默认至少 3 条并分布在至少 2 个真实小标题下。每条计入最低数量的内容都必须可追溯到 Script 中具体的事实、例子、对比或应用，含有帮助定位的具体信息；只有笼统主题概括、元话语或可套用于多篇讲座的泛化句不计数。每个新生成/重做的 notes 面板在第一个计分 blank 之前至少先提供 1 条具体、Script-grounded 的无 blank 导航内容。无 blank 内容不得包含 canonical answer 或使相邻 blank 可由题面直接猜出。十个 blank 的位置必须覆盖 note 的前部、中部和末尾，默认每一类至少 2 个，不得让绝大多数 blank 都落在句末，也不得出现没有任何上下文的孤立 blank。 | `MAJOR` | 先统计无 blank 内容行及其 section 分布，确认首个 blank 前已有具体 signpost，再逐条建立 Script evidence 映射并判断具体性、导航价值和答案泄露；按 blank 前后的实义词位置分类：前部为 blank 前至多 1 个实义词且后有内容，末尾为 blank 后无实义词且前有内容，其余为中部；检查三类各至少 2 个。 |
| `QR-026` | Part 1 的 form/note/table completion 必须避免系统性句末设空。只要结构和 Script 证据允许，整 Part 至少应出现前部、中部和末尾 blank，句末 blank 不得超过十题中的七题；若当前 form/table 结构不适合位置变化，必须记录理由。新生成或重做的 Part 1 notes/table 还必须具有清楚的记录结构，并在每个 narrator 题号窗口内至少提供 1 条具体、不含 blank、不泄露答案的 Script-grounded signpost；同时按 `QR-031` 提供场景标题。页面结构可自然跨越 narrator 窗口，但每题证据仍须符合 `SC-019`。边框样式、字体、间距和非破坏性分页可以在内容人工 review 后完善；只要题号、blank、signpost 和层级可可靠读取，就不阻断首轮内容 review。 | `MINOR`；十题全部/绝大多数机械句末设空、无导航结构、证据跨 narrator 窗口或版面使必需内容不可读时可升为 `MAJOR` | 直接从 Question Word 分类 Part 1 每个 numbered blank 的前/中/末位置；检查三类覆盖、句末数量、记录结构、每个窗口的无 blank signpost 和 `QR-031` 标题。视觉 polish 单独记入 `visual_qc_status`。 |
| `QR-027` | Part 1 应覆盖有意义的事实类别与答案形式组合，不得在十题内无理由地用三题或以上反复测试同一微型答案类别（例如连续/分散的三个价格数字），也不得让纯数字/时间/金额答案挤占拼写型答案。对新生或重做的 Part 1，默认纯数值答案不超过 4/10，并至少有 4 题需要写出两个或以上字母的单词/短语；单字母和通用缩写不计入该拼写最低数。Script 确实缺少替代证据时可保留，但必须记录阻断或保留理由。 | `MINOR`；造成题目构念明显单一或未经理由超过纯数值上限时 `MAJOR` | 为 Q1–Q10 标注 answer category 和 response form，统计同一微型类别、纯数值题、有意义拼写题；超过阈值需人工复核并记录理由。 |
| `QR-028` | 自规则版本 2026-07-30 起，新生成 multiple-selection 题只允许五选二：必须使用恰好 5 个选项、`Choose TWO letters` 指令和两个计分答案。该规则持续有效，直至正式 rubric 修订明确撤销；不得因“临时”字样、时间经过或单次例外而自动失效。 | `MAJOR` | 扫描全部 `Choose TWO/THREE` 题组，核对选择数、选项数和 answer key；发现 `Choose THREE` 或非 5 选 2 即失败，并记录适用的 rubric 版本。 |
| `QR-029` | 相邻 single choice/multiple-selection 题必须提供足够的听音、判断和转移作答时间。除通用 20 词 micro-density 外，选择题必须单独记录精确口语词间隔；若有音频则优先记录秒数。低于 40 个口语词或 10 秒只触发人工 processing-load 复核，不自动判错；必须给出 keep/rewrite 理由，reviewer 明确报告过密时不得以超过 20 词自动关闭。 | `MAJOR`；仅触发阈值但经人工确认可保留时不形成 finding | 建立 choice-pacing 表，记录相邻选择题证据位置、词数/秒数、题面负担和结论。 |
| `QR-030` | 选择题正确答案的位置不得形成明显可预测模式。完成语义、证据和 no-audio 审查后，应使用由 Set、Part、源 DOCX 哈希组成 seed 的可复现受约束洗牌重排 options，并同步 answer key。对 5 题以上的三选一/四选一题组，所有可用字母都必须出现，频次差不得超过 1，连续相同字母不得超过 2；matching 题组至少使用两个答案字母且连续相同字母不得超过 2，若 `QR-012` 指令禁止复用则答案还必须全部不同；同一套含两个以上五选二题组时，不得重复相同无序答案对，三个以上题组整体应覆盖至少 4 个 A–E 字母。不得为了字母分布改变正确性、选项平行性、证据顺序、reuse contract 或题型边界。 | `MINOR`；违反明确的 non-reuse contract 或出现可被利用的系统模式时 `MAJOR` | 从最终 Word answer key 提取每个 single-choice/matching group 和五选二 block 的字母序列；matching 报告 reuse contract、字母种类、最大连续次数和频次；同时记录五选二无序 pair、seed/digest 和任何证据阻断理由。 |
| `QR-031` | 新生成或重做的 Part 1 note completion 必须包含一个简短、具体、非答案泄露的场景/主题标题，帮助考生快速识别记录对象。标题不得包含 canonical answer、唯一答案词或可直接推出答案的类别提示。历史原件仅因缺标题不倒推失败。 | `MINOR`；标题泄露答案时按 `QR-008`/`SC-012` 为 `MAJOR` | 检查 Part 1 指令后、首个计分 blank 前是否存在非通用标题；隐藏答案后复核标题不会缩小到唯一答案。 |
| `QR-032` | single choice 和 multiple-selection 的选项必须在逻辑上独立且作为候选答案互相排斥。不得使用直接互补对、包含/被包含关系、同一维度的上下位嵌套、或成对矛盾，使考生无需听音即可由一个选项确认或排除另一个。 | `MAJOR`（造成无音频泄露、多个有效答案或非唯一选择）；不影响作答的轻微平行性问题为 `MINOR` | 对每题建立 pairwise option-logic matrix，逐对记录 `independent`/`complementary`/`overlap`/`containment`/`contradiction` 和结论；与 `QR-006`/`QR-008` 联合判定。 |
| `QR-033` | 新生或重做的 matching 必须选择并声明一种一致的 reuse contract。非复用题组必须有至少一个 surplus option（`option_count >= item_count + 1`），答案映射一对一；允许复用的题组不强制 surplus，但每个复用关系仍须独立通过 `QR-042`。所有 options 必须处于同一语义层级；全部 options（含额外/最终未使用项）均须进入 answer-blind compatibility、Script 来源、自然度和听后排除审查。若 Script 无法提供足够的自然候选和可区分关系，必须更换命题点或题型，不得制造填充项。 | `MAJOR`（instruction/audit/key 合同不一致、non-reuse 无余量或发生复用、语义层级不一致、无 Script 来源、题面泄露或听后多解） | 检查 instruction 与 `reuse_allowed`；仅在 non-reuse 时检查 `option_count >= item_count + 1` 和答案全部不同；对每个 item 与全部 options 建立 compatibility/provenance/after-audio resolution audit。 |
| `QR-034` | 题目定位负担必须可控。每个 stem/item 至少保留一个清楚且不泄露答案的 Script signpost；matching 默认使用原词或近原词的服务、地点、主题等定位标签，不强制同义替换。不得使用 `opening overview`、`first practical comment`、`next observation`、`immediately after`、`first issue defined` 这类只描述转录位置/顺序而不标明实际语义对象的空泛 item。不得同时重度改述题目焦点和正确选项，使考生在听音前先解码题面。 | `MINOR`；妨碍定位、公平性或使题目变成转录顺序测试时 `MAJOR` | 逐题记录 retained signpost、focus paraphrase、correct-option paraphrase 和 localisation result；确认 item 含有可听的语义名词或对象，而不是只有顺序副词；若两端均改述，说明为何仍能从连续局部证据直接定位。 |
| `QR-035` | 新生或重做的 Question Word 在 Part 标题与首个题组之间不得另外插入 `You will hear ...` 类场景预告句。该信息已由可听 narrator 提供，重复出现会破坏标准题卷层级并占用版面；若特定 asset 或无障碍说明确实需要，必须单独记录理由。 | `MINOR`；与题组指令冲突或造成答案提示时 `MAJOR` | 只扫描 annotated Script 附录之前的题卷正文，检查 Part 标题后的额外场景预告句。 |
| `QR-036` | 对新生或重做的 single choice，每个错误 option 必须在对应 narrator 题号窗口内被可听 Script 实质激活，并能记录为 `rejected`、`corrected`、`downgraded` 或 `mentioned_wrong_relation`；对新生/重做的五选二，A–E 五个 options 全部必须有对应实质证据状态。`not_supported`、空 evidence 或仅凭题面想象的 distractor 不能通过新改 choice 验收；应改测 Script 实际提及/否定/修正的局部内容，不得为此未授权改录音 Script。新生/重做 matching 的全部 options（包括未使用项）也必须满足 `QR-041` 的 Script-first 来源与自然措辞门槛；只有历史 matching 的纯激活缺口仍按 `SR-008` 报告。 | `MAJOR` | schema v5 distractor audit 覆盖所有新改 choice/matching options；单选激活比必须 3/3，五选二必须 5/5，新改 matching 必须全部有 Script provenance，并按 `QR-042` 逐题证明听后唯一性，同时仍检查可信性、互斥性、QR-021 和 no-audio fairness。 |
| `QR-037` | 题目必须测试可听内容的事实、条件、原因、建议或观点，不得把“录音先/后说了什么”、“紧接着提到什么”或“某问题后的第一项”这类转录顺序本身作为命题目标，除非时序/流程本身就是 Script 明确教授的内容。 | `MAJOR` | 检查 stems/items 是否只由 `first/next/final/immediately after/before the talk moves` 等 discourse-order 表达组成；若去掉顺序词就没有语义考点，必须重写。 |
| `QR-038` | 新生或重做的 Part 4 notes 应优先测试讲座中的词汇性内容词，不应以纯数字、日期、年份、时间或序数词作为计分 blank；只有 Script 缺少同等公平的词汇性答案时才可保留，并必须记录 evidence-based 理由。 | `MINOR`；无理由地导致 Part 4 构念失衡时 `MAJOR` | 为 Q31–Q40 标注 answer form，标记纯数值/序数答案及保留理由；优先改测同一 Script 窗口中证据唯一的 one-word 内容词。 |
| `QR-039` | 对新生或重做的 single choice，两个错误 option 的实质 Script 证据都必须出现在决定性正确答案证据之前，且各自距答案证据不得超过前 3 个完整句子；同一句中先出现的错误信息可记为 0 句。对新生/重做的 multiple-selection，所有错误 option 必须在完成该题组所需的最后一个决定性正确答案证据之前出现，且距该最终证据不得超过前 3 个完整句子。答案之后才出现的内容不得倒算为干扰项；仅处于同一 narrator window 不足以通过。找不到足够前置近距干扰项时，应更换题目所测试的局部信息，不得修改可听 Script。 | `MAJOR` | 在 distractor audit 中逐个错误 option 记录 `evidence_sentence_index`、`decisive_answer_sentence_index`、`relative_position=before`、`sentences_before_answer`（0–3）和 `locality_result=PASS`；索引差与句距必须一致。任何 `after`、负数、超过 3 句、字段缺失或 result 非 PASS 均失败。 |
| `QR-040` | Completion 题组中考生在听音前可见的所有非 answer-key 文本——包括主题标题、小标题、无 blank signpost、示例、其他 carrier 及相邻题——不得复现该题 canonical answer，也不得以单复数、常规屈折变化或同一事实的近直述使 blank 无需听音即可确定。每个 completion group 必须在隐藏 Script 和 answer key 后执行 group-scope leakage audit；仅扫描 blank 所在单句不足以证明通过。 | `MAJOR` | 按题组收集所有考生可见文本，对每个 completion canonical answer 扫描 exact phrase、大小写和简单屈折变化，并人工复核同一事实的语义泄漏。新生/重做版本出现任一未解决命即失败；修改后同步重跑 `QR-008`/`AL-014` 相邻题检查。 |
| `QR-041` | 新生或重做的 single choice、multiple-selection 和 matching 必须采用 Script-first 设计：先从对应 narrator window 的明确事实、动作、建议或关系建立候选池，再生成题干与 options。每个显示 option 必须记录最小 `script_source_phrase`、题面 `display_text`、`source_relation` 和 `naturalness_result`；matching 的未使用 option 也不例外。题面应优先保留最接近 Script、学生熟悉且不泄露答案的自然表达，可直接保留必要原词或固定术语；不得仅为制造词面差异改成生僻、抽象、翻译腔或迂回措辞，也不得引入 Script 未出现的对象、动作或关系。找不到足够自然候选时必须更换命题点或题型。 | `MAJOR`（无 Script 来源、引入新事实、matching 填充项或措辞妨碍公平定位）；仅轻微自然度润色为 `MINOR` | schema v5 audit 对照最终 Word，逐项检查 source/display 一致性、`naturalness_result=PASS`、题干词汇重复与 `answer_leakage_result=PASS`；自动扫描只作 triage，语义与自然度必须人工确认。 |
| `QR-042` | 每个 matching item 在听完其决定性证据后必须恰好只剩一个受支持 option。Audit 必须列出 `correct_option`、唯一元素的 `supported_options_after_audio`，以及覆盖题组全部 option ID 的 `option_resolution_after_audio`（每项含 `id`、`state`、最小 `evidence`）；其余 option 必须被记录为 `rejected`、`downgraded` 或 `wrong_relation`。允许复用时，同一 option 对每个 item 都要有独立证据；任何未使用 option 或另一选项若对某 item 获得同等支持，均属多解。 | `MAJOR` | schema v5 逐题核对 supported 列表、resolution 全覆盖、Word key 和 reuse contract；确认每题仅一个 `supported`，其他状态均有证据。 |
| `QR-043` | 对每个新生成或重做的一词 completion，必须把已选 canonical answer 与同一 narrator/question window 内其他可用的 Script-grounded 候选进行可避免拼写负担复核。只有候选各自通过 Script 原词、字数、证据、唯一性、语法、题组泄漏、证据顺序和密度要求时，才属于可互换的 `equally_valid` 候选；若其中存在拼写负担更低的候选，应优先选择该候选。低词频、不透明拼写、不熟悉的专名/技术词以及缺少自然拼读说明只作为人工 review signal，不得由自动词频阈值直接判错。困难词确为目标词汇/技术构念，或不存在同等有效的低风险候选时可以保留，但必须记录候选比较和保留理由。不得通过改成数字、单字母、通用缩写，或削弱 `QR-027`/`QR-038` 的词汇性与拼写构念要求来满足本规则。 | `MINOR`；单题已使公平评分不可靠，或多个新改题累计后明显把测试构念转向非预期正字法难度时为 `MAJOR` | 保留 candidate/source hash-bound spelling-risk audit，逐题记录 `canonical_answer`、`narrator_window`、`risk_signals`、`local_alternatives_considered`、`intended_construct`、`decision`、`severity` 和 rationale。每个 alternative 至少记录 Script 来源、是否同窗口、其他规则门槛是否全部通过及相对拼写负担。自动 validator 只核验哈希、覆盖、字段和人工结论一致性，不自行计算词频或判定词汇难度。 |
| `QR-044` | 对新生成或重做的 Part 4 note-completion，canonical answer 以 `-ing` 结尾时必须先做人工形态复核；后缀扫描只是 triage，不得把 `building`、`training`、`engineering` 等所有表面 `-ing` token 自动判为可避免的 V-ing。若确认 canonical answer 是动词 V-ing 形式，且同一局部决定性证据窗口（同一决定性句或相邻 1–2 句，并位于同一 narrator window）内存在一个 Script-grounded、完整同形、一词的非 V-ing 名词或形容词，且该候选独立通过字数、证据、唯一性、语法、题组泄漏、命题对齐、证据顺序和密度门槛，则应重写 carrier，使该非 V-ing 候选获得唯一支持。词汇化名词不属于本规则的 V-ing 命中；固定技术术语或就是目标构念的 V-ing 可经理由记录后保留。不得为避免 V-ing 而派生 Script 未出现的词形、跨证据窗口拼接，或改动未授权的可听 Script。 | `MINOR`；单题已造成明显可避免的拼写/形态处理负担，或同一 Part 多次发生并累计使测试构念偏移时升为 `MAJOR`；仅表面后缀命中、无同等有效替代项或经记录的固定术语不形成 finding | 扫描 Q31–Q40 canonical answers 的 `-ing` 后缀；对每个命中在 hash-bound completion audit 中记录人工 classification、同一局部证据窗口内已考虑的非 V-ing 一词名词/形容词、各规则门槛、carrier 唯一性、decision、severity 和 rationale。自动工具只检查后缀、字段和人工结论一致性，不自动判定词性或“等价替代”。 |

## 题型专项检查

- **Completion**：检查字数限制、blank 语法、原词要求、每空答案数量，以及 carrier 是否采用自然、可定位的最小必要改述；允许保留不泄露答案的 Script signpost。按 `QR-040` 对每个 completion group 的标题、signpost、示例、所有 carrier 和相邻题执行 group-scope pre-listening leakage audit，包括 canonical answer 的简单屈折变化。对新生/重做的一词 completion，另按 `QR-043` 比较同一 window 内其他分别通过全部题目门槛的 Script-grounded 候选，避免可替代的拼写负担；词频只作人工 triage。Part 4 还须按 `SC-018`/`QR-023`/`QR-025` 检查固定 notes 形式、具体且可追溯的无 blank 导航内容及前/中/后 blank 分布；按 `QR-044` 对 Q31–Q40 的 `-ing` 后缀命中做人工形态和同一局部证据替代项复核，不将词汇化名词或固定术语机械判错。
- **Multiple choice**：检查选择数量、`QR-032` pairwise option logic、最终决定、音频激活的干扰项、`QR-039` 前置近距位置、`QR-029` pacing 和 `QR-030` answer-position pattern；single choice 还须按 `QR-021` 检查连续 1–2 句证据窗口，并按 `QR-034` 保留定位 signpost。新生成的 multiple-selection 必须遵守 `QR-028` 五选二限制。
- **Matching**：按 `QR-012`/`QR-033` 检查题面声明的 reuse contract；仅 non-reuse 题组强制 `item + 1` 余量与答案一对一。item 和 option 可以保留 Script 原词或 signpost，不要求为了词面变化而同义改写。每个 item 必须记录至少两个 `compatible_options_without_audio`，并按 `QR-042` 证明听后只剩一个 supported option；全部 option（含额外/未使用项）均按 `QR-041` 进入 Script provenance、naturalness、compatibility 与 resolution 审查，并按 `QR-034` 控制定位负担。
- **Plan/map/diagram**：检查 asset、方向系统、起点、路径和 label 唯一性。
- **Short answer**：检查问题词、答案粒度、数量要求和字数限制。
